Importar nuevo archivo CSV

Seleccioná el archivo CSV actualizado con las piezas y el stock del sistema. La importación reemplazará la base de datos actual.

Qué ocurrirá al importar

  • Se borrarán todos los movimientos de conteo.
  • Se borrarán todos los conteos y las cantidades físicas.
  • Se eliminarán todos los inventarios anteriores.
  • Se eliminarán todas las piezas actuales.
  • Se cargarán las piezas del nuevo CSV.

Atención: esta operación elimina el historial de inventarios y no se puede deshacer. Si la conexión falla durante el proceso, la carga puede quedar incompleta. No cierres la página mientras se está importando.
